# Aramark — Marko Data & AI Platform

> Marko is Aramark's data and AI platform. It publishes 60 documented REST APIs covering the Aramark organization hierarchy, point of sale, labor, inventory, product and recipe data, service execution and facilities operations. Every request is authenticated with an `apikey` header issued per registered application after an approval step. The production host is `https://marko.aramark.net`; `qa-marko.aramark.net` and `dev-marko.aramark.net` are the published test and development hosts.

This file is generated by API Evangelist (apievangelist.com) from Aramark's own published OpenAPI documents and developer portal. It is not published by Aramark.

## Start here

- [Marko Developer Portal](https://marko-developers.aramark.net/): registration, login, API products

- [OpenAPI source repository](https://github.com/aramarkservicesinc/markoapis): Aramark publishes every spec as JSON and YAML

## How to call it

- Auth: `apikey: <your application key>` request header. Register an application on the portal, choose API products, wait for approval, then a key is generated.
- Cache control: send `bypass-cache: true` to read past the gateway cache.
- Responses: `{"status": "Success" | "Error" | "Not Found", "count": <n>, "<collection>": [...]}`. An application error can arrive inside an HTTP 200, so read `status`, not just the status code.
- Gateway faults are a different shape: `{"fault":{"faultstring":"...","detail":{"errorcode":"..."}}}`. An unkeyed call returns 401 `steps.oauth.v2.FailedToResolveAPIKey`.
- Most operations pivot on `org_value`, an identifier for a level of the Aramark organization hierarchy. Resolve it from the Organization APIs first.

## Not available

- No MCP server, no A2A agent card, and no `/.well-known/` document on any Aramark host (all probed 2026-09-04, all 404).
- No SDK or client library in any public registry; the portal ships raw HTTP code samples instead.
- No published pricing, rate limits, SLA, status page, deprecation policy or changelog.
- No webhooks, events or AsyncAPI surface.
